## נעים להכיר, אני אריאל

אני מפתח כלים שמקלים על לימוד, חיפוש ועבודה עם ידע — עם דגש על עברית ועל טקסטים תורניים.

הפרויקטים שלי משלבים חיפוש סמנטי מקומי, יישומי לימוד למחשב, תוספים לדפדפן ותכנון לימוד אישי. מעניין אותי לחבר בין פתרון טכני לבין חוויית שימוש נוחה: למצוא את המקור המתאים, לקרוא טקסט בצורה נעימה ולעבוד בממשק שמותאם לעברית.

## מה מחבר בין הפרויקטים שלי

- **גישה נוחה למקורות** — חיפוש סמנטי, אינדוקס טקסט ועיבוד עברית.
- **כלים שמשרתים את הלימוד** — ממשקי קריאה, יישומי מחשב ותכנון הספק אישי.
- **תשומת לב לחוויית השימוש** — תמיכה מימין לשמאל, תאריכים עבריים וניווט נוח במקלדת.

לצד הפרויקטים האלה, אני עובד גם עם גרסאות משלי לפרויקטי קוד פתוח קיימים: [תיקון קידוד ב־PDF עברי](https://github.com/arieldaniely/pdf-missing-encoding-fixer-heb), [עימוד דפי תלמוד בדפדפן](https://github.com/arieldaniely/daf-renderer) ו־[D-PAD Player](https://github.com/arieldaniely/D-PAD-Player).
